# sujaykolpuru.com

A deliberately simple personal site, served by GitHub Pages at
[`sujaykolpuru.com`](https://sujaykolpuru.com/).

The site is dependency-free: edit `index.html`, commit, and GitHub Pages handles
the rest. `CNAME` must continue to contain `sujaykolpuru.com`.

The legacy `/about`, `/love`, and `/now` URLs are retained as redirects so old
links do not break.
